# Lab 03 — Design an editable bakery flyer

**C818 · Topic 2 · 75 minutes · Version 1.0**

## Goal

Create an A5 flyer with source-checked copy and a complete text proof.

## What you’ll build

creative/sourdough/flyer-a5.pptx or another editable layout source, flyer-a5.pdf, flyer-copy.md, image-prompt.txt and text-proof.md.

## Prerequisites

Labs 1–2. PowerPoint, Google Slides or another layout editor with PDF export. Optional ChatGPT image generation; the supplied typographic checkpoint supports accounts without image generation.

## Steps

### 1. Prepare the asset folder

Create creative/sourdough inside C818-marketing. Copy this lab’s assets/design-brief.md into it. Keep the selected course and ledger attached to the Work task.

### 2. Plan two visual routes

Paste prompts/task.txt into Work. Review the two proposed routes before production: finished loaf and hands at work. Choose one route and explain the decision in creative/sourdough/design-decision.md.

### 3. Approve the exact copy

Ask Work to save flyer-copy.md with the title, four-week duration, S$680 scenario fee, Saturday schedule, Orchard Road campus, CTA and tagline. Compare each factual line with selected-course.json. Omit tax claims, discounts and remaining seats.

### 4. Create or choose the visual

If image generation is available, request an original natural-light sourdough image with no text, faces, chef identities or logos. Save the exact prompt as image-prompt.txt and the image as sourdough-visual.png. If unavailable, use the typographic checkpoint and record no generated image used.

### 5. Create the editable layout

Ask Work to create an editable A5 portrait flyer, or open PowerPoint and set Design > Slide Size > Custom Slide Size to width 14.8 cm and height 21 cm. In Google Slides use File > Page setup > Custom with the same dimensions. Use Georgia headings, a sans-serif body and the academy palette. Keep important text at least 10 mm from the trim edge.

### 6. Place facts as live text

Use text boxes for every factual line rather than relying on lettering inside the generated image. Keep one primary CTA: View course details in the demo catalogue. Add classroom draft wording in a small but readable footer. Do not insert a fake QR code or a made-up public registration URL.

### 7. Export and proof

Save the editable source and export PDF. Open the PDF at 100 percent. Transcribe every visible word and number into text-proof.md, including the footer. Beside each offer fact record the source field.

### 8. Request a bounded correction

Attach the proof and PDF to Work. Ask it to find factual, hierarchy or readability problems. Choose one specific correction, preserve the verified facts, export again and update the proof.

### 9. Save the checkpoint

Keep the editable source, PDF, copy, proof and prompt together. If the task stalled, use checkpoints/flyer-a5.pptx and its PDF as a classroom starting point and revise it against your own brief.

## Task prompt

Copy `prompts/task.txt` into the Work task. Review the plan before authorising production.

```text

Using workflow.md, brand.md, selected-course.json and claim-ledger.csv, plan two A5 portrait flyer routes for Cook & Bake Academy BAK-101. Explain the hierarchy, image choice and CTA for each, then wait for my choice. After the choice, produce editable flyer copy and an editable layout file if your tools support it. Use the academy brand, not the trainer deck palette. Exact tagline: Learn it. Make it. Take it further. Keep all factual text editable, add a readable classroom draft footer and return a full text proof with source fields. Use no discount, seat scarcity, invented trainer or real booking promise. Generate imagery only if available and keep its prompt. Stop before publishing.

```

## Test it

- The A5 page is 148 × 210 mm and essential text stays inside a 10 mm safe area.

- Title, fee, duration, schedule and campus match the selected record.

- The saved PDF is readable at 100 percent and has one CTA.

- An editable source and complete visible-text proof exist.

## Troubleshooting

**Generated image text is misspelled:** Generate the visual without text and use editable text boxes for all copy.

**The facts crowd the layout:** Remove nonessential prose before reducing body text; preserve the required offer facts and CTA.

**No image tool is available:** Use the included typographic checkpoint and record the limitation; the output still needs an editable source and proof.

## Challenge

Create a second flyer for the career-changer audience without altering the course facts; explain the changed benefit emphasis.

## Reflection

How did hierarchy make the primary action easier to find?
