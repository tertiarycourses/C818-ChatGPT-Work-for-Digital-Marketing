# Cook & Bake social post

## Prepare

Read `../brand-voice/SKILL.md`. Verify every course, fee, date, campus, offer, and link against `cnbacademy/data/courses.json` (resolve from the project root). This catalogue is the only offer-fact source. The campaign/selected-course.json record must be an exact extract of it; claim-ledger.csv records checks. If a fact is missing or the sources disagree, omit it and flag it for confirmation.

Write for the requested platform while keeping the brand warm, practical, and specific. Default to a useful teaching, making, or behind-the-scenes angle. Make no more than one in five posts a hard sell; if the recent posting mix is unknown, avoid a hard sell or ask for the last four posts before planning one. Do not depict or identify a learner without consent.

## Hand back exactly

1. **Hook:** fewer than 10 words.
2. **Caption:** fewer than 120 words, in brand voice, with exactly one clear call to action. Use a verified link only if the catalogue provides it.
3. **Hashtags:** exactly five, with three topical and two local. Keep them relevant to the actual post.
4. **Alt text:** a concise description of the actual supplied image. If no image exists, label it **proposed alt text** and make clear it describes a proposed visual.
5. **Fact check:** list the source file for each factual claim and flag any requested claim omitted because it was unverified.

Return one ready-to-review package for each requested platform. Do not publish or schedule it unless the user separately asks.
